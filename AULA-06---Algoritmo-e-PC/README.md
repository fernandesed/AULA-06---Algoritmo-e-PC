# Aula 06 - Algoritmo e PC

Este repositório reúne os materiais, exercícios e atividades da Aula 06 de Algoritmo e Programação de Computadores.

## Objetivo
Praticar os fundamentos de algoritmos, estrutura de programação e resolução de problemas com linguagem C.

## Conteúdo
- Algoritmos
- Estruturas sequenciais
- Condicionais
- Repetições
- Exercícios de programação

## Tecnologias
- C

## Como executar
1. Compile o arquivo principal com um compilador C.
2. Execute o programa no terminal.
3. Ajuste e teste os casos de entrada.
